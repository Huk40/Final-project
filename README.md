TODO-планировщик

Описание проекта:
TODO-планировщик - приложение для управления задачами. Сервер написан на
Go, данные хранятся в SQLite.

Приложение может:
1 создавать просматривать редактировать и удалять задачи
2 отметить задачу выполненной
3 задать дату
4 задать комментарий
5 создавать повторяющиеся задачи
6 сортировать задачи 
7 искать задачи

Выполненные задания со звёздочкой

Порт сервера можно переопределить переменной окружения `TODO_PORT`.
Путь к SQLite-базе можно переопределить переменной `TODO_DBFILE`.
Реализованы расширенные правила повторения по дням недели и дням месяца.
Реализован поиск по заголовку и комментарию.
Реализован поиск задач по дате в формате `ДД.ММ.ГГГГ`.
Аутефикацию и созданию докер образа планируеться реализовать после сдачи базового функционала

Локальный запуск:

Для запуска потребуется Go версии, указанной в `go.mod` (Go 1.26.1 или новее).

Перейдите в корневую директорию проекта и выполните:

go mod download
go run .


После запуска откройте в браузере:
http://localhost:7540/


Для выбора другого порта или файла базы данных в PowerShell:
$env:TODO_PORT = "7550"
$env:TODO_DBFILE = "C:\data\scheduler.db"
go run .


После этого приложение будет доступно по адресу:
http://localhost:7550/

Запуск тестов
Тесты обращаются к уже запущенному HTTP-серверу. Сначала запустите сервер в
одном терминале:

go run .

Затем из корневой директории проекта выполните во втором терминале:
go test ./tests

Для запуска отдельного теста:

go test -run ^TestNextDate$ ./tests
go test -run ^TestAddTask$ ./tests
go test -run ^TestTasks$ ./tests
